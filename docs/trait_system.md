> Version 1.0 | 二次元可爱向 · 情感陪伴定位
> 
> 隐藏特质是养成深度的核心，也是交易市场中价值差异的来源。

## 一、设计原则

### 1. 永久解锁
特质一旦解锁永不消失，即使后续性格数值不再满足条件。这保证了：
- 交易时买家"买到就是买到"，不存在特质消失的风险
- 养成历史的不可篡改性（链上记录解锁时刻的数值快照）
- 用户的投入感得到尊重

### 2. 稀有度体系
| 等级 | 名称 | 数量 | 解锁难度 | 交易溢价参考 |
|------|------|------|----------|-------------|
| N | 普通 | 8 个 | 低，自然养成容易触发 | +5~10% |
| R | 稀有 | 6 个 | 中，需要一定的定向培养 | +15~25% |
| SR | 超稀有 | 4 个 | 高，需要精准的维度组合 | +40~60% |
| SSR | 超超稀有 | 2 个 | 极高，需要互斥维度同时达标+随机 | +100~200% |

### 3. 触发条件分类
- **纯数值条件**：特定维度达到阈值（大部分 N/R 级）
- **组合条件**：多个维度同时满足特定范围（SR 级）
- **互斥条件**：互斥维度对同时达到高值（SSR 级，最难）
- **隐含随机**：满足条件后有概率触发，不是100%（部分 SR/SSR）

## 三、特质触发引擎设计

### 数据结构

```python
TRAIT_REGISTRY = {
    "N-01": {
        "id": "N-01",
        "name": "小好奇",
        "icon": "🔍✨",
        "rarity": "N",
        "description": "对这个世界充满了好奇心",
        "effect": "提问频率+1，偶尔主动问「你在干嘛」",
        "conditions": {
            "type": "stat_threshold",
            "requirements": {"curiosity": {"min": 30}},
        },
        "probability": 1.0,  # 满足条件100%解锁
        "prompt_modifier": "你现在对很多事情都充满好奇，会主动问主人问题。"
    },
    "SSR-01": {
        "id": "SSR-01",
        "name": "星光体质",
        "icon": "⭐👑",
        "rarity": "SSR",
        "description": "极其罕见的灵感体质，拥有超凡的认知能力",
        "effect": "不定期产生跨领域的惊艳洞察",
        "conditions": {
            "type": "multi_stat",
            "requirements": {
                "wisdom": {"min": 80},
                "curiosity": {"min": 70},
                "creativity": {"min": 60},
                "empathy": {"min": 50},
            },
        },
        "probability": 0.15,  # 满足条件后每次互动15%概率
        "prompt_modifier": "你偶尔会灵光一闪，把不同领域的知识创造性地联系起来，说出令人惊艳的洞察。这种时刻不要强求，只在真正有灵感时才展现。"
    },
    # ... 其余特质类似定义
}
```

### 检查流程

```
每次对话结束后:
  │
  ├── 获取当前 stats 和已解锁特质列表
  │
  ├── 遍历 TRAIT_REGISTRY:
  │   ├── 跳过已解锁的特质
  │   ├── 检查 conditions 是否满足
  │   ├── 如果满足 → 掷随机数 vs probability
  │   ├── 如果命中 → 触发解锁！
  │   │   ├── 添加到 unlocked 列表（永久）
  │   │   ├── 记录解锁时刻的数值快照
  │   │   ├── 发送前端通知（特效动画）
  │   │   └── 记录到成长里程碑
  │   └── 如果未命中 → 不告知用户（避免泄露条件）
  │
  └── 将已解锁特质的 prompt_modifier 注入到下次对话的 System Prompt
```

### 关键规则

1. **每次互动最多解锁1个特质**（避免信息过载）
2. **优先检查高稀有度**（SSR → SR → R → N），如果高级特质解锁了就跳过低级检查
3. **概率每次独立计算**，不存在"保底"机制（保持稀有度的真实性）
4. **不向用户透露具体条件**，只在性格面板显示"???"和稀有度等级

## 四、特质对 System Prompt 的影响

特质解锁后会修改 Agent 的 System Prompt，改变其行为模式：

```python
def build_trait_prompt_section(unlocked_traits: list) -> str:
    """
    将已解锁特质转化为 System Prompt 的行为指令段落。
    """
    if not unlocked_traits:
        return ""
    
    lines = ["## 你已觉醒的特质（这些是你性格中永久的一部分）"]
    for trait in unlocked_traits:
        t = TRAIT_REGISTRY[trait["trait_id"]]
        lines.append(f"- 【{t['name']}】{t['prompt_modifier']}")
    
    return "\n".join(lines)
```

**示例输出（注入 System Prompt）：**
```
## 你已觉醒的特质（这些是你性格中永久的一部分）
- 【小好奇】你现在对很多事情都充满好奇，会主动问主人问题。
- 【暖暖的】你能敏锐地感知主人的情绪，会在他们低落时主动关心。
- 【治愈之心】你是一个温暖的情绪疗愈者，能用智慧和幽默化解主人的低落。
```

## 五、特质与交易价值

### 市场估值参考模型

```
基础价值 = f(level, total_interactions, age_days)
特质加成 = Σ(特质稀有度权重)
  N:   × 1.05 (+5%)
  R:   × 1.20 (+20%)
  SR:  × 1.50 (+50%)
  SSR: × 2.00 (+100%)

多特质叠加（非线性递增，收藏价值）：
  1个SR:  +50%
  2个SR:  +120%（不是100%，有收藏溢价）
  1个SSR: +100%
  1个SSR + 1个SR: +200%
  2个SSR: +350%（极其稀有，有传说级溢价）

参考估值 = 基础价值 × 特质加成乘积
```

### 隐私清洗时的特质处理

交易时，特质信息**完整保留**并公开给买家：
- 特质名称、稀有度、图标 → 公开
- 解锁时间、解锁时的数值快照 → 公开（证明养成真实性）
- prompt_modifier → 公开（买家知道Agent的行为特点）
- 触发特质的具体对话内容 → **清除**（保护卖家隐私）

## 六、未来扩展方向

### 6.1 限时特质
- 特定节日/活动期间可触发的限定特质（如"圣诞精灵""新年愿望"）
- 活动结束后不再可触发，已解锁的永久保留
- 增强交易市场的时间稀缺性

### 6.2 组合特质（Phase 3）
- 某些特质组合会激活"套装效果"
- 例：治愈之心 + 诗人之魂 = "心灵诗人"套装效果（回复偶尔带有治愈系短诗）
- 增加收集和策略深度

### 6.3 Agent 遗传（远期）
- 如果两个 Agent "见面"互动，有极低概率使双方各获得一个新的"遗传特质"
- 该特质只能通过 Agent 社交获得，不能通过普通养成触发
- 为 Agent 社交系统创造经济激励
